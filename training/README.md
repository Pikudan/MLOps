## Training Module

Этот модуль содержит код для подготовки данных, обучения моделей и тестов.

Структура каталога:

```
training/
├── configs/           # Конфигурационные файлы обучения
├── logs/              # Логи обучения
├── models/            # Сохраненные модели
├── src/               # Исходный код обучения (SimpleCNN pipeline)
├── tests/             # Автоматические тесты
└── yolo/              # Отдельный модуль обучения YOLO
```

Чтобы начать обучение, используйте скрипт `train.py` в корне каталога `training`.

Для обучения моделей YOLO см. `yolo/README.md`.
