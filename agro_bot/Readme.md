# AgriLink Бот для агрономиста

## Описание
AgriLink Бот для агрономиста - это телеграм-бот, разработанный для помощи агрономам в управлении сельскохозяйственными задачами и общения с фермерами. Он предоставляет такие функции, как уведомления о событиях, чатовую поддержку и доступ к информации о задачах фермера.

## Модули

1. **main.py:** Этот модуль служит входной точкой для бота. Он инициализирует бота, настраивает промежуточное ПО, планирует уведомления и запускает процессы.

2. **notification.py:** Обрабатывает функцию уведомлений бота

3. **pagination_info.py:** Обеспечивает функциональность для пагинации в пролистовывании календаря фермера

4. **pagination_kb.py:** Создает встроенные клавиатуры для пагинации 

5. **restart.py:** Управляет командой перезапуска, сбрасывая состояние бота и историю для пользователей и предоставляя свежий старт.

6. **router.py:** Определяет маршрутизацию входящих сообщений и запросов обратного вызова к соответствующим обработчикам на основе их типов и состояний.

7. **state.py:** Определяет состояния, используемые в конечном автомате (FSM) бота для управления взаимодействиями пользователей 

8. **text_messages.py:** Содержит функции для форматирования и генерации текстовых сообщений

9. **unauthorized_handler.py:** Обрабатывает сообщения от пользователей, которые не являются авторизованными агрономами
